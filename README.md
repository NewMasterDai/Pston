# A SteamOS desktop utility

A lightweight shell script that fetches and applies an opinionated Templates configuration for Linux systems using `curl`.

!CURRENTLY WIP, USE AT YOUR OWN DISCRETION!

## Features

- a .pptx file
- a .docx file
- a .sh file
- a .xlsx file
